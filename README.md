# Tableau
<h1>Tableau - Superstore Sales Performance Dashboard</h1>


<h2>Description</h2>
This project presents an interactive sales performance dashboard built in Tableau, analysing revenue, profitability and discount impact across regions and product categories. The goal of this project was to stimulate a real-world business scenario and provide insights that could support decision making for sales and management teams. 
<br />


<h2>Languages and Utilities Used</h2>

- <b>Kaggle data set</b>
- <b>Tableau</b>
